# وُصلة — المنصة اللوجستية الذكية

**منصة لوجستية عالمية تعمل عبر تيليجرام**، تربط الأفراد والسائقين والمتاجر والمؤسسات والشركات في سوق موحّد متعدد الأطراف. نموذج الاشتراك الثابت يحل محل العمولات التقليدية، والهندسة المعمارية الهجينة (Modular Monolith + Microservices) تضمن قابلية التوسع لمليار مستخدم.

---

## 🌟 الرؤية

منصة من المستقبل — قادرة على استيعاب وإدارة وتشغيل أكثر من **مليار مستخدم** بكفاءة وسلاسة وعبقرية.

## 🎯 الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| **14 بوت تيليجرام** | عميل، سائق، تاجر، مؤسسة، أسطول، إدارة، دعم، مناديب، مشرفين، عمليات، مرسل، تحليلات، شحن، سوق مفتوح |
| **نموذج اشتراك ثابت** | 0% عمولة — السائق يحتفظ بكامل أجره |
| **محرك توزيع ذكي** | Greedy → Batched Bipartite → AI — تصاعدي حسب الحجم |
| **تعدد الأطراف** | أفراد، سائقين، متاجر، مطاعم، مؤسسات، سلاسل، شركات، جهات حكومية |
| **خدمات متعددة** | مشاوير، توصيل، شحن، حجوزات، مشاوير خاصة، أسطول مؤسسات |
| **بوابات دفع محلية ودولية** | سداد، مدى، STC Pay، Stripe، Apple Pay، Google Pay |
| **طبقة ذكاء اصطناعي** | NLP، توصيات، تنبؤ بالطلب، كشف احتيال، تسعير ديناميكي |
| **الامتثال التنظيمي** | هيئة النقل، PDPL، ضريبة القيمة المضافة، الفوترة الإلكترونية |

## 🚀 البدء السريع

### المتطلبات
- Bun 1.2+
- Supabase account
- Telegram Bot tokens (من @BotFather)

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/reev-zeev/upaaz-.git
cd upaaz-

# تثبيت الاعتماديات
bun install

# إعداد المتغيرات البيئية
cp .env.example .env
# املأ القيم في .env

# تشغيل قاعدة البيانات
bun run supabase start

# تطبيق التهجيرات
bun run db:migrate

# تشغيل الخوادم
bun run dev:api     # API Server
bun run dev:bots    # Telegram Bots
bun run dev:admin   # Admin Dashboard
```
